# Portfolio Website - Abigiya Getachew

A modern, responsive portfolio website showcasing frontend development and UI/UX design work. Built with a clean off-white and black monochrome aesthetic.

## Features

- **Responsive Design** - Fully responsive layout that works on all devices
- **Interactive Elements**
  - Project filter dropdown with category filtering
  - Mobile navigation menu
  - Contact form with validation
  - Success modal for form submissions
  - Email copy to clipboard functionality
  - Back to top button
- **Project Showcase** - 3-column grid layout with project cards featuring:
  - Thumbnail images with hover zoom effects
  - Project descriptions and technology tags
  - Live preview and source code links
- **Smooth Animations** - Fade-in effects, hover transitions, and scroll progress indicator
- **Contact Form** - Validated form with error states and success feedback

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Custom styling with CSS variables
- **JavaScript (ES6+)** - Interactive functionality
- **Font Awesome** - Icons
- **Google Fonts** - Outfit, Plus Jakarta Sans, and Syne fonts

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/nabi0l/Codveda-tech-level-1-Tasks.git
```

2. Navigate to the project directory:
```bash
cd Codveda-tech-level-1-Tasks
```

3. Open `index.html` in your web browser

No build process or dependencies required - simply open the HTML file in any modern browser.
